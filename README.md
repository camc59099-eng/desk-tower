# Desk Tower (read-only)

A pixel-art, read-only visualisation of a research-only **paper/demo** trading desk.
It does not trade, place orders, sign in anywhere or move money. Data is a sanitized static snapshot (no account numbers or personal details).
https://camc59099-eng.github.io/desk-tower/
Fonts: Press Start 2P and VT323 (SIL Open Font License, see `fonts/`).
